# Layout and interoperability

Choose page size, margins and section structure before tuning spacing. Use keep-with-next for headings and table header repetition for long tables; inspect actual pagination instead of estimating page count from characters. A section break can change page orientation, numbering and header/footer linkage. Retain these links intentionally when inserting a landscape table or appendix.

Keep source DOCX/ODT separate from PDF exports. Writer, Word, Pages and browser editors can differ in fonts, floating shapes, fields and line breaking. Test in the requested final application where available. A Writer PDF can verify content and its own layout, not guarantee identical Word pagination. Use libreoffice-automation only when batch conversion or headless rendering is needed.

Measure meaningful content integrity: expected headings, tables, list numbering, key amounts, revision/comment presence, and embedded media. Compare affected pages visually at readable scale. Watch for substituted fonts, cut table cells, footnotes displaced onto blank pages and page numbers that restart unexpectedly. For translated documents inspect expanded text and non-Latin glyph coverage.

Do not claim an accessible or compliant document from a visual inspection alone. When accessibility is requested, inspect heading hierarchy, language, image alternatives, table structure and reading order using available application checks. When signed or protected documents are involved, preserve the original and explain any effects of requested edits. Deliver a clearly named editable source plus a preview if useful, with remaining application-specific fidelity limitations stated.
