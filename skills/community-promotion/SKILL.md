# Community promotion

Use for niche-site discovery, asking questions, answering threads, blog comments, directory/resource entries, feedback, outreach, product launches and guest articles. These workflows do not require a marketing objective. A website build or discovery-only request alone does not authorize external posting. Preserve explicit publishing authorization across steps and resumptions; do not repeatedly ask for permission already granted. A request to find suitable venues and post includes choosing eligible destinations within that scope.

Read [long tasks and submissions](references/long-tasks.md) for multi-venue work, browser/API execution, moderation and resumption. Use the existing todo plan for the objective, authorized scope, venue work and evidence; do not create another task manager. Carry the task through discovery, preparation, authorized execution and outcome verification. A blocked venue does not block independent eligible work.

Find the audience's actual problem. For questions, include context, attempts and a precise request without inventing facts. For answers, solve the actual question within the venue. For promotion, create something useful even if every promotional link is removed: a worked solution, reproducible example, original observation, comparison with limitations, or practical resource. Disclose affiliation where relevant. Do not invent personal experience, endorsements, identities or community participation.

Read [venue selection](references/venue-selection.md) when finding destinations or evaluating account/API access. Read [execution and learning](references/execution-learning.md) when preparing, publishing or measuring a contribution. Load only the relevant reference.

Check each destination's current posting, promotion, automation and AI-content rules. An available API or logged-in browser does not establish permission by itself; apply the user's task authorization. Prefer supported APIs with the user's authorized credentials, or an available interactive browser permitted by the venue. If authentication or automation restrictions block a venue, record the blocker and pursue an eligible alternative; do not repeatedly attempt signups or bypass challenges.

Optimize for helpful conversations and qualified visits, not backlink counts or posting volume. Tailor each contribution to its audience; avoid duplicated campaigns, fake grassroots activity, unsolicited bulk messages and ranking manipulation. Link only when useful and permitted; a profile link is not a loophole around promotion rules.

Before an authorized submission, verify the account, destination, exact text, disclosures and links. After an ambiguous response, inspect the existing post before retrying. Return published URLs and observed outcomes separately from drafts and estimates.
